# Megabit Trajectories

Real coding sessions recorded step by step. An AI agent explores a codebase, fixes a bug, runs tests, gets reviewed, and we capture every single move.

## The Task

We picked a real bug from an open source Python library ([Rich](https://github.com/Textualize/rich)). The bug was: code inside markdown table cells loses its syntax colors. We gave this to an AI agent and said "fix it."

## How We Made It

1. Cloned the repo at the commit before the fix
2. Gave the agent a ticket describing the bug
3. Agent explored the code, found the problem, wrote a fix
4. A reviewer agent checked the work and asked for changes
5. Agent iterated until all tests passed
6. Every step was recorded

## What Happened

The agent made 153 tool calls over about 56 minutes. It read files, grepped for patterns, ran tests, edited code, and went through 2 review rounds. Final result: 956 tests passed, 0 failed.

## The Hard Part

We used free APIs because we're broke. Free APIs are slow, rate limited, and sometimes just fail. We had to build a fallback chain that tries multiple providers one after another. It worked, but it took a lot of debugging.

### `feedback/` (reviewer reports)

Markdown reports from each review round. Shows what the reviewer found and what needs fixing.

### `logs/` (full agent logs)

Raw logs from the coder and reviewer agents. Includes retry journal for debugging.
